# ❌⭕ Tic-Tac-Toe Game

A fun and interactive **Tic-Tac-Toe** game built with HTML, CSS, and JavaScript. Play with a friend locally and see who wins!

## 🚀 Live Demo

[Click here to play!](https://ojasvsingh71.github.io/tik-tak-toe/) 

## 🛠 Tech Stack

- **HTML** for the structure  
- **CSS** for styling  
- **JavaScript** for game logic  

## 💡 Features

- Two-player turn-based game (X vs O)
- Win detection logic for all possible patterns
- Winner announcement screen
- Game reset and New Game buttons
- Fully responsive design

## 🎮 How to Play

1. Player 1 starts with "X", Player 2 is "O".
2. Click on any empty box to make a move.
3. The first player to match 3 symbols in a row (horizontal, vertical, or diagonal) wins!
4. Click **New Game** or **Refresh** to play again.
